# Is It Worth It? Calculator

A simple web app that helps you decide whether a purchase is worth it by calculating the **cost per use**.

## What It Does
You enter:
- The **price** of an item
- The number of times you expect to **use it**

The app calculates:

**Cost per use = Price ÷ Uses**

It makes it easier to judge the real value of a purchase.

## How to Run
1. Clone or download the repository
2. Open `index.html` in your browser
3. Thats it!
